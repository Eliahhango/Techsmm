# TechSMM React mirror

## Run

```bash
npm install
npm run dev
```

Open the Vite URL shown in the terminal.

The downloaded pages and CDN assets are under `public/site/`. React maps the mirrored HTML pages to client-side routes and injects their local styles/assets. Server-side login, orders, payments, and API behavior remain unavailable because they were not part of the downloaded public files.
